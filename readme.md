# Les Petits Plats

Site web de recettes de cuisine, entièrement codé from scratch en HTML/CSS/JavaScript avec une architecture modulaire et des performances optimisées.

## Description

Les Petits Plats est une application web permettant de découvrir et rechercher des recettes de cuisine savoureuses et faciles à réaliser. Le site met en pratique des compétences avancées en développement Front-End, notamment la création d'une interface utilisateur performante et accessible conforme aux standards W3C, et l'implémentation de fonctionnalités JavaScript optimisées avec une architecture modulaire.

## Comment démarrer

Ce projet est un site statique HTML/CSS/JavaScript. Pour le lancer, il est recommandé d'utiliser un service comme l'extension Live Server dans VSCode :

1. Installez l'extension Live Server dans VSCode si ce n'est pas déjà fait
2. Ouvrez le dossier du projet dans VSCode
3. Clic droit sur [`index.html`](index.html) et sélectionnez "Open with Live Server". Cela lancera un serveur local (généralement sur http://127.0.0.1:5500)
