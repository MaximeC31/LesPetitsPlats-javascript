Ce projet met en pratique des compétences avancées en développement Front-End, notamment la création d'une interface utilisateur performante et accessible conforme aux standards W3C, et l'implémentation de fonctionnalités JavaScript optimisées. Il inclut également l'analyse comparative de deux algorithmes afin de garantir la meilleure performance du moteur de recherche, tout en respectant les bonnes pratiques de Green Code et de sécurité.
